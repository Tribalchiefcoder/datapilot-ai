# DataPilot AI

An AI-powered business data analysis platform that helps users explore, edit, and understand their datasets through an interactive spreadsheet and an AI business analyst.

## Project Status

Day 1 — Initial development.

## Planned Features

- Upload CSV, Excel, and JSON datasets.
- View and edit data in an interactive spreadsheet.
- Sort and filter records.
- Perform basic spreadsheet calculations.
- Ask natural-language questions about business data.
- Generate business insights and recommendations.
- Visualise revenue and profit trends.
- Export edited datasets.

## Technology Stack

**Frontend:** React, JavaScript, CSS  
**Backend:** Python, Flask  
**Data Analysis:** Pandas (planned)  
**AI Integration:** AI API (planned)  
**Visualisation:** Chart.js (planned)

## Development Setup

The frontend and backend run as separate services.

Frontend:
- Navigate to `frontend/`.
- Install dependencies using `npm install`.
- Start the development server using `npm run dev`.

Backend:
- Navigate to `backend/`.
- Create and activate a Python virtual environment.
- Install Flask and Flask-CORS.
- Start the server using `python app.py`.
